### 🚀 Top Project: Quant AI Terminal
An institutional-grade, real-time stock market intelligence platform.
- **Tech:** React, FastAPI, XGBoost, OpenAI GPT-4o, FinBERT, WebSockets, RAG Vector DB
- **Highlight:** Built an autonomous quantitative pipeline that ingests breaking news, matches it against historical vector embeddings, parses sentiment polarity, and predicts 1-hour directional stock price movements via a Platt-scaled XGBoost model. Features a live Bloomberg-style React dashboard.
- [🔗 View Project Repository](https://github.com/Prathamesh-000/AI-Stock-Market-Intelligence)
